# 个人本体 · 使用说明书（最终用户版）

> 适用版本：BUILD 20261012H（macOS 本机运行）
> 这份说明只讲"你能用它做什么、怎么用"。内部实现与设计细节见 `docs/07`、`docs/08`。

---

## 一、它能帮你做什么

大多数人现在的处境是这样的：

- 你的资料散在十几个 App 里：证件在相册、地址在购物软件、关系在微信、合同在邮箱；
- 每次有新的服务要你"授权"，你只能点"同意"，不点就没法用；
- 事后你想知道"我的身份证被谁用过"，基本查不到；
- 智能体开始替你办事之后，它会把你的资料记下来，然后一直用下去，你不在场。

这个工具想解决的就是这三件事：

**1）把属于你的东西收在一处，而且只有你能打开。**
资料、关系、约定、地址、资产、结论，都存在你本机的一个加密文件里。口令只在你手上，忘了谁也打不开。

**2）把"授权"从一次性勾选，变成每次一次。**
不是注册时同意一辈子，而是"这一次、这几项、给这一家、十分钟后失效"。

**3）让每一次授权都留下能拿出来的记录。**
谁在什么时候用了你哪几项资料、给了谁、什么用途——你能查，必要时能导出。

一句话：**它不帮你做事，它管"谁能拿你的什么做什么"。**

## 二、第一次打开

1. 打开控制台（默认 `http://127.0.0.1:8765`）。
2. 第一次使用会让你设置一个口令。**这个口令就是钥匙**：
   - 忘了口令，数据打不开，我们也没有后门；
   - 建议用一句你记得住的长句子，而不是短密码。
3. 解锁后，左侧是两层菜单：

```
我的世界        总览 · 我 · 圈 · 事 · 地 · 财 · 识
规则与能力      界 · 器 · 场景切片 · 场景实例 · 场景预演 · 对外交付与反馈 · 判定记录 · …
```

## 三、八个日常页面

### 1）我：你的资料

**能干什么**：存放姓名、证件号、手机号、住址、过敏信息、资质证书、紧急联系人。

**怎么用**：
1. 「我」→「新建一份资料」→ 起个名字（例如"我的实名信息"）→ 逐行加字段。
2. 加完点「拆分资料项」，把整块资料拆成**一项一项**——只有拆开，才能"只授权其中一项"。
3. 每一项后面有两个按钮：
   - **查看**：二次确认后显示明文，**这次查看会留下一条记录**（第几次都能看到）；
   - **删除**：只删这一条字段，资料本身和其它字段都还在。

**要点**：列表默认显示掩码（`33**********34`），这是故意的——掩码能防止你随手被人看到屏幕。

### 2）圈：你的关系

**能干什么**：把"谁能做什么"从一个个个体，变成一群一群的人。

**怎么用**：
1. 「圈」→「新建圈」→ 选类型（家人 / 朋友 / 工作 / 客户 / 同学 / 服务 / 组织）→ 填"我在这一圈里的身份"（例如父亲、下属、甲方）。
2. 进详情页加成员：只填**关系**（身份、亲近程度、最后互动时间）。
3. 给这一圈写一句"默认边界"，例如"可看我的行程空闲，不给具体内容"。

**要点**：
- 圈里**只存关系，不存对方的证件、住址、家庭**——那是别人的隐私，不该进你的库；
- 移出成员会**立刻**让他失去这一圈的授权，并留下变更记录；
- 一个圈如果还有授权规则指向它，是删不掉的（系统会告诉你还有几条）。

### 3）事：约定了什么、什么时候到期

**能干什么**：车险续保、租约到期、体检预约、和某人的承诺。

**怎么用**：「事」→「新建一条」→ 选类型 → 填到期日 → 填"提前几天提醒"。
清单会按剩余天数排序：逾期的标红、7 天内的标黄。做完了点「完成」。

### 4）地：你在哪些地方

**能干什么**：家、公司、父母家、常去的地方、行程。

**怎么用**：「地」→「新建地点」→ 名称、类型、地址（**填到街道就够**）、可选填"到达半径"。

**要点**：地址本身就能推出你住哪、常去哪，所以它默认是敏感级；坐标默认不采集，除非你要做"到达提醒"。

### 5）财：你有什么、花了什么

**能干什么**：账户、房产、车辆、保险、订阅、债务、税务，以及流水。

**怎么用**：
1. 上半部分是资产：名称、类型、**只填掩码**（`**** 1234`）、金额摘要（"余额 5 万左右"）、到期日。
2. 下半部分是流水：「记一笔」→ 选资产、填金额（支出填负数）、对方、分类、日期。

**要点**：
- 资产**只存掩码与摘要**，不存完整卡号；
- 流水存在**独立的加密账本**里：记一百笔也不会拖慢其它数据，而且**永远不参与对外授权**。

### 6）识：你的结论是怎么来的

**能干什么**：把"前提 → 结论 → 依据 → 出处 → 例外"一起记下来。

**怎么用**：「识」→「新建一条」→ 至少写一句结论；其余四栏能填就填。

**要点**：这一页现在只做"结论卡"；照片、文档、语音的索引还没做。

### 7）界：谁能做什么，一眼看全

**能干什么**：四个统计（生效中 / 草稿 / 已暂停 / 已撤回），其中会单独告诉你"有几条是给圈的"。

**怎么用**：只读总览。要改某条规则，去它所属的场景页操作。

### 8）器：哪些设备和智能体在碰你的数据

**能干什么**：列出已接入的智能体（名称、可信度、状态、最近活动、授权范围）。

**怎么用**：点「从接入清单同步」，把已经接入的智能体列进来。

**要点**：同步**只搬清单信息**（名称、状态、范围、时间），**不复制密钥**；密钥仍在原来的文件里，认证路径没变。

## 四、智能体怎么用你的数据（最重要的一节）

### 1）每次预填：值从本体来，但要你点头

在场景里，你可以声明"这一项由本体提供"，例如：

```
【本场景会用到的本机资料】
预定人姓名 ｜ 用于实名登记
预定人证件号 ｜ 用于实名登记
```

之后智能体调用时：

- **你没有确认** → 它只看到掩码（`张*`、`33********34`）和一句"需要你先确认"；
- **你确认之后** → 本体才把真值交给它，并附上一句使用约束：仅限本次业务、不得写入记忆、不得转述、结束后不得保留。

页面上有一块红色提示，写着：**确认后这些值就交出去了，发出去收不回来**。这句话是字面意思——一旦进入智能体所连模型的上下文，我们无法回收。所以请只勾这次真正要用的那几项。

### 2）按圈授权：一次授权给一群人

在场景里生成授权规则时，"规则适用于谁"的下拉里，除了具体的人，还有 **"圈：工作"** 这样的选项。

- 选中之后，工作圈里的每个人都能调用这条规则；
- 你把某人移出这个圈，他**立刻**失去这条授权；
- 「界」页面会告诉你，现在有几条规则是"给圈"的。

### 3）查看明文会留痕

每次点「查看」看明文，都会写一条记录：哪一项、什么时候、第几次查看。记录里**不含明文本身**。

## 五、场景与判断（原有的专业部分）

- **场景切片**：用一段话描述一个场景，系统拆出资源、动作、条件，并提示可能漏掉的信息；
- **场景实例**：确认之后的场景，在这里管理"每次必填"、"每次预填"、"长期偏好"与授权规则；
- **场景预演**：用模拟输入跑一遍，不执行真实动作；
- **对外交付与反馈**：专业判断对外交付的层级、定价与调用方反馈；
- **判定记录**：每一次正式交付的记录，包括被拒绝的（拒绝也留痕）。

## 六、几条安全常识

1. **口令就是一切**：忘了就打不开，没有找回。
2. **数据只在本机**：不联网同步；你看到的"加密文件"就是全部数据。
3. **掩码是默认的**：需要看明文时再点，别养成随手展开的习惯。
4. **授权越窄越好**：能给"这一次"，就别给"永久"；能给"一项"，就别给"整份"。
5. **给别人办事时**：对方发来的证件，用完就删，不要存进任何一份资料或任何一圈。

## 八、常见问题

**Q：忘记口令怎么办？**
A：打不开。这是设计选择，不是缺陷——如果厂商能帮你打开，那它就不是你的数据。

**Q：数据存在哪？**
A：本机 `data/ontology.po.json`，一个加密文件。拷走它但没有口令，等于一堆乱码。

**Q：我把某个圈删了，里面的人会怎样？**
A：他们失去这一圈的授权；他们的"关系记录"随圈一起消失；如果还有授权规则指向这个圈，系统会先拦住你，告诉你有几条。

**Q：智能体会不会偷偷把我的证件号存下来？**
A：我们做不到技术上的拦截。我们能做的三件事：只给它本次要用的那几项；在返回里写死"不得留存"；把这次给了什么记下来。真正拦得住的办法是"由本机代替它提交"，那是后续工作。

**Q：能导出给别人看吗？**
A：目前可以查看与打印页面内容；"可导出的证据包"（授权记录 + 使用记录）还没做，是下一步。

**Q：为什么每次查看明文都要弹一次窗？**
A：因为每一次查看都可能是泄露点。确认一次、留一条记录，代价很小。

**Q：我不小心删了一条资料项，能恢复吗？**
A：不能。删除前会弹窗点名要删的是哪一项，请看清再点。

**Q：这个工具会替我去订酒店吗？**
A：不会。它只回答"能不能"和"给谁看"，真正下单的是智能体；本机代做是未来的方向。

## 九、把手机通讯录接进来（2026-10 新增）

**为什么需要**：圈要靠人填。手输几百个人不现实。

### 做法（两步）

```
第一步 · 拉取（在终端做，因为浏览器读不到 USB）
   手机：设置 → 关于手机 → 连点"版本号"7 次 → 开发者选项 → 打开「USB 调试」
   用数据线连到 Mac → 手机上点「允许」
   终端执行：sh scripts/pull-android-contacts.sh
   → 生成 data/contacts-import.json（600 权限，只在运行目录）

第二步 · 导入与分圈（在界面做）
   登录 → 圈 → 任意一圈 → 「从通讯录补人」→ 勾选 → 加入这一圈
   若还没导入：圈里会显示「去『器』里导入通讯录」的引导
   器 → 「数据来源 · 通讯录」可以看导入了多少条、以及清除它们
```

### 这些数据的安全位置

```
· 全部标为 restricted：不参与任何对外授权、不进契约、导出默认排除
· 加入圈时只写"关系"（圈内身份、亲近程度），电话邮箱仍留在通讯录集合里，不进圈
· 器里可一键清除导入的通讯录；圈里的成员不受影响（他们只是关系，不含联系方式）
```

## 十、智能体代表谁（代理关系）

如果某个智能体是替**你**办事的，可以在器里设置"代表你"：

```
器 → 代理关系 → 某个智能体 → 代表 [ 你的名字 ▾ ] → 立刻生效
```

设置之后：

- 它自动继承你的**圈**与**直接给你的**授权；
- 取消这个设置，或你被移出某个圈，它对应的权限**立刻失效**。

判定结果里会写明凭什么：`self`（本人）、`ancestor`（上级）、`circle`（所属圈）、`acting_for`（代理）。
