### 2026-10-02 追加：智能体授权页仍显示中文的根因（#3）

**不是界面文案漏译** —— `renderAgentAccess` 里的 32 条中文串**全部已收录（0 缺失）**。
真正的来源是**后端数据**：

- `backend/agent_access.py` 的 `SCOPES: dict[str, str]` 是 `范围键 → 中文标签`：
  `catalog → 读取资源类型、动作与场景实例`、`rules → 读取授权规则`、
  `decisions → 读取判定记录`、`principals → 读取主体名称`、
  `check → 提交授权检查（会写入判定记录）`、`preview → 预演场景实例`、
  `feedback → 写回场景反馈与长期偏好`
- 前端 app.js 里**没有任何范围标签映射表**（`'catalog'` 字面量 0 处、`scopeLabel` 0 处），
  说明页面上的范围名称直接来自接口返回 → **切英文后仍是中文**。

**修法**（与字段标签本地化同构，参考 `_localize_scene_labels`）：
1. 在 `agent_access.py` 增加 `SCOPES_EN`（同键英文标签）；
2. 在返回智能体清单的接口里按 `X-Display-Language` 选择标签（`GET /v1/agents` 与其子路径）；
3. 注意该接口属于**授权路径**，改动后必须跑 `tests/test_agent_access.py`（24 项）确认授权判定未受影响。

**注意**：范围标签也用于拒绝理由（`agent_access.py:191` 的 `SCOPES.get(scope, scope)` 出现在
"MCP 客户端未被授予…"的提示里）——那部分属于给智能体看的说明，可按同一语言设置处理。
