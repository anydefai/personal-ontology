## 三、实现方式（这次不再用 DOM 后处理）

上一轮我做坏的原因：**先渲染整页，再用 JS 去找元素、挪位置** —— 结果容器找错，卡片静默失效，页面还是三套界面并存。
这一轮改为：

1. **卡片与第二步标题直接写在渲染函数里**（`renderSlices` 的模板字符串中），不做任何事后 DOM 查找。
2. 三种方式的**面板本来就是三个独立函数**（模型起草 / 一次性写入 / 逐行写入），模板里按选择只拼一个。
3. **保存后自动填入第三步**：复用已有的全局刷新钩子（保存成功 → 刷新 → 滚到第三步）。
4. **每块做完当场验证**：做完一块我用真实浏览器截图级别的方式核对（先在页面上确认元素存在且可见），再给你看，你点头我再做下一块。
