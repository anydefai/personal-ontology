# 判定模型策略"数据化"设计（待确认，未写代码）

> 方向：业界做法 ①（判定逻辑尽量做成数据，不是代码）。本文只把**模型内部还能调的参数**
> 变成框架字段；模型的**算法形状**（加权求和 / 要件求值 / 表达式求值）仍然是代码，不可改。
> 每一步的**默认值都等于今天的行为**，并有"逐字段相等"的回归测试兜底。

## 二、① 命中分值（部分命中）

**现状**：命中即算满（1）✗ —— 权重表里写 0.35，命中就加 0.35。
**改后**：每个信号可以带一个分值，默认 **1**（不写就是今天的算法）。

```
字段：signals[].score_value  （数字，默认 1；范围 0–1，允许 0 表示"只记录不影响打分"）
算法：score += weights[dimension] × score_value(signal) × 例外系数(dimension)   ← 只在末尾乘了一项
行格式（逐行输入 / 一次性写入，同一语法）：
     客户集中度>50 = 客户集中度 大于 50 ｜ 市场            ← 不写分值 = 1（与今天完全一样）
     营收增长率>35 = 营收增长率 大于 35 ｜ 财务 ｜ 0.5      ← 第三段是分值
界面：第三步「我观察什么」面板，每行加一个"分值"小输入（默认 1，留空即 1）
理解：0.5 = "这个信号只是部分证据"；1 = "它成立就算一条完整证据"
```

## 三、② 结论优先级（可配）

**现状**：顺序写死 —— 组合规则 → 打分线 → 兜底 → "无明确结论"。
**改后**：框架里可声明顺序，默认与今天相同。

```
字段：precedence = ["rules", "bands", "fallback"]   （默认值；可改成 ["bands", "rules", "fallback"]）
语义：按数组顺序取第一个能给出结论的；都没有 → "无明确结论"
界面：第三步「打分线」面板里加一个下拉：
     ● 组合规则优先（默认，今天的做法）
     ○ 打分线优先（先看分数落在哪档，规则只在没有分档命中时用）
校验：数组里出现未知项 → validate 报错（不静默忽略）
```

## 四、③ 阈值调整支持"乘法"

**现状**：基准线的条件调整只能加（`delta`）✗ —— `监管环境=收紧 → -0.10`。
**改后**：也可以乘（`factor`），用来表达"按比例缩放"。

```
字段：thresholds.adjustments[].factor  （数字；与 delta 二选一）
行格式：
     监管环境=收紧 → -0.10        ← 加法（今天就有）
     营收增长率>50 → ×1.2         ← 乘法（新增：写 × 前缀即乘法）
算法：命中时 base = base × factor（按声明顺序依次应用，与 delta 可混用）
界面：无需改（同一文本框）；提示文案加一句"写 × 表示乘法"
```

## 五、④ 切片"另存为"（复制一份含模型与全部参数）

**现状**：想基于一条切片做另一版，只能手工重填 ✗。
**改后**：切片页加一个「另存为新切片」按钮。

```
行为：复制当前切片的 framework（含 model、权重、阈值、信号、规则、公式、边界、交付、计费）
     与 boundaries/delivery/billing，另存为一条新切片（草稿状态）
     · 不复制：授权规则（新切片默认未启用）· 判定记录 · 置信度状态（新切片为"未验证"）
命名：默认"<原名> 副本"，可改
界面：切片页第一步附近加按钮（与"新建我的切片"同一排，避免又多一个入口）
接口：POST /v1/scenario-slices/{id}/duplicate  → 返回新切片 id
```

## 六、兼容与验收（每一步都要过这一关）

```
· 老切片不含新字段 → 引擎取默认值 → 行为必须与今天【逐字段相等】
· 专门测试：同一份框架 + 同一组数据，在"不带新字段"时判定包逐字段相等（沿用第 0 步的做法）
· 每个新字段都要有 validate 提示：值域不对、未知优先级项、delta 与 factor 同时给
· 界面行为测试（tests/test_ui_behavior.js）补断言：分值输入存在、优先级下拉存在、另存按钮存在
```

## 七、分四步，每步单独验收

| 步 | 内容 | 验收标准 | 重启 |
|---|---|---|---|
| **1** | 命中分值 | 不写分值时判定包逐字段相等；写 0.5 时分数减半；行格式第三段可解析 | 是 |
| **2** | 结论优先级 | 默认顺序下逐字段相等；切成"打分优先"后，有分档命中时不再用规则 | 是 |
| **3** | 阈值乘法 | 只写 delta 时相等；`×1.2` 生效且 reasoning_path 显示"×1.2" | 是 |
| **4** | 另存为切片 | 副本的 framework 与原切片逐字段相等；副本无授权规则、状态为草稿 | 是 |
