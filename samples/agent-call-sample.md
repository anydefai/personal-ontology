# 交给智能体（WorkBuddy）的调用样本

> 依据：这条切片的「使用说明」（契约）—— 10 个字段全部必填、允许用途「并购尽调、投资决策」、
> 金额上限 1,000,000,000、要求承诺不转售、单价 ¥1200/次（演示）、交付有效期 1 天。
> **把 slice_id 换成你自己的那条**（下面用的是你贴过的 ID）。

---

```json
{
  "tool": "judge_professional_slice",
  "arguments": {
    "slice_id": "scenario_slice_40e0e4caca0e",
    "data": {
      "不动产权属": "有瑕疵",
      "未决诉讼金额占比": 7.5,
      "对外担保": "有未披露",
      "业绩对赌条款": "无",
      "数据合规结论": "基本合规",
      "市盈率": 46,
      "行业平均市盈率": 32,
      "客户集中度": 58,
      "交易结构": "股权收购",
      "标的为国资背景": "否"
    },
    "request": {
      "caller": "某某资本 · 投资部",
      "purpose": "并购尽调",
      "amount": 300000000,
      "no_resale": true
    }
  }
}
```

## 二、HTTP 调用（等价，便于自查）

```bash
curl -s http://127.0.0.1:8766/v1/scenario-slices/scenario_slice_40e0e4caca0e/judge \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer <会话令牌>" \

    },
    "request": { "caller": "某某资本 · 投资部", "purpose": "并购尽调",
                 "amount": 300000000, "no_resale": true }
  }'
```

## 三、字段与取值（照抄，别写别的）

| 字段 | 类型 | 允许的写法（必须完全一致） |
|---|---|---|
| 不动产权属 | 选项 | 清晰 / 有瑕疵 |
| 未决诉讼金额占比 | 数字 | 例如 7.5（表示 7.5%） |
| 对外担保 | 选项 | 无 / 有已披露 / 有未披露 |
| 业绩对赌条款 | 选项 | 有 / 无 |
| 数据合规结论 | 选项 | 合规 / 基本合规 / 不合规 |
| 市盈率 | 数字 | 例如 46 |
| 行业平均市盈率 | 数字 | 例如 32 |
| 客户集中度 | 数字 | 例如 58（表示 58%） |
| 交易结构 | 选项 | 股权收购 / 资产收购 |
| 标的为国资背景 | 选项 | 是 / 否 |

- **十个字段一个都不能少**：少任何一项 → 只返回 `decision:「信息不足，无法判断」` + `missing_inputs`（不会猜）。
- `purpose` 只能是 **并购尽调** 或 **投资决策**（别的用途会被边界拒绝）。
- `amount` 不得超过 **1,000,000,000**。
- `no_resale` 必须为 **true**（这条切片要求承诺不转售）。

## 四、会收到什么

```json
{
  "decision": "…结论…",            "severity": "高 / 中 / 低",
  "score": 0.0,                     "basis": ["附上的依据"],
  "signals": { "权属瑕疵": true, "…": false },
  "required_inputs": ["十个字段名"], "missing_inputs": [],
  "confidence_status": "unverified",
  "decision_id": "…判定记录号（审计用）"
}
```
**不会收到**：权重、阈值、组合规则、内部框架 —— 这些不外发。

## 五、两个前置条件（否则会 403 / 拒绝）

1. 这条切片必须在控制台**已确认并启用**（内容不够的切片不能启用 ✓ 这是硬门槛）。
2. 调用方**程序**必须被授权：控制台启用时把该程序选为被授权方（或经 MCP 批准）。

## 六、故意少一项会怎样（用于自查）

去掉 `数据合规结论` 再调一次，应得到：

```json
{ "decision": "信息不足，无法判断", "severity": "未判定",
  "missing_inputs": ["数据合规结论"] }
```
若还给了结论 → 说明契约没生效，请把原文发我。
