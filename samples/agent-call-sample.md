# 调用方（智能体）调用样本

> 依据：当前切片的「使用说明」。**11 个字段全部必填**；`slice_id` 换成你自己的那条。
> 用途只能是 **并购尽调** 或 **投资决策**；金额不得超过 **1,000,000,000**；必须 `no_resale: true`。

---

```json
  "arguments": {
    "slice_id": "scenario_slice_40e0e4caca0e",
    "data": {

```

## 2. HTTP 调用（等价，便于自查）

```bash
curl -s http://127.0.0.1:8766/v1/scenario-slices/<你的切片ID>/judge \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer <会话令牌>" \
  -d '{
    "data": {
      "行业": "房地产", "不动产权属": "有瑕疵", "未决诉讼金额占比": 7.5,
      "对外担保": "有未披露", "业绩对赌条款": "无", "数据合规结论": "基本合规",
      "市盈率": 46, "行业平均市盈率": 32, "客户集中度": 58,
      "交易结构": "股权收购", "标的为国资背景": "否"
    },
    "request": { "caller": "某某资本 · 投资部", "purpose": "并购尽调",
                 "amount": 300000000, "no_resale": true }
  }'
```

## 3. 字段取值（照抄，写别的等于没填）

| 字段 | 类型 | 允许的写法 |
|---|---|---|
| 行业 | 选项 | 房地产 / 制造业 / 新能源 / 互联网 / 医药 / 金融 |
| 不动产权属 | 选项 | 清晰 / 有瑕疵 |
| 未决诉讼金额占比 | 数字 | 例如 7.5（表示 7.5%） |
| 对外担保 | 选项 | 无 / 有已披露 / 有未披露 |
| 业绩对赌条款 | 选项 | 有 / 无 |
| 数据合规结论 | 选项 | 合规 / 基本合规 / 不合规 |
| 市盈率 | 数字 | 例如 46 |
| 行业平均市盈率 | 数字 | 例如 32 |
| 客户集中度 | 数字 | 例如 58（表示 58%） |
| 交易结构 | 选项 | 股权收购 / 资产收购 |
| 标的为国资背景 | 选项 | 是 / 否 |

## 4. 这组数据实测会得到（我用真实引擎跑过）

```
结论：风险极高，建议终止      严重度：极高
分数：0.725                    动态阈值：1.76
命中：权属瑕疵 · 诉讼未决 · 担保未披露 · 对赌缺失 · 客户集中度高
依据：《民法典》物权编 · 《公司法》股权转让相关规则
```
返回体里会有的字段（说明里写明的）：`decision` `severity` `score` `basis` `signals`
`required_inputs` `missing_inputs` `confidence_status` `decision_id`。
**不会返回**：权重、阈值、组合规则、内部框架。

## 5. 故意少一项会怎样（自查用）

去掉 `数据合规结论` 再调一次，应得到：

```json
{ "decision": "信息不足，无法判断", "severity": "未判定",
  "missing_inputs": ["数据合规结论"] }
```
若还给了结论 → 说明契约没生效，请把返回原文发我。

## 6. 两个前置条件（否则 403 / 拒绝）

1. 这条切片必须在控制台**已确认并启用**（内容不够的切片启用会被拒 ✓ 并逐条告诉缺什么）。
2. 调用方**程序**必须被授权：控制台启用时把该程序选为被授权方。
